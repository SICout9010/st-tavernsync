# TavernSync

[English](README_EN.md) · [สำหรับนักพัฒนา](README_DEV.md)

ซิงก์ตัวละคร แชท lorebook พรีเซ็ต เพอร์โซนา และการตั้งค่าของ SillyTavern **ระหว่างหลายเครื่อง** — Push จากเครื่องหนึ่ง แล้ว Pull อีกเครื่อง บนเซิร์ฟเวอร์ที่คุณควบคุมเอง

ค่าเริ่มต้นเปิด **เข้ารหัสต้นทางถึงปลายทาง (E2EE)** เพื่อกันคนดูเซิร์ฟเวอร์อ่านเนื้อหา แต่แลกมากับขั้นตอนและความเข้าใจที่มากขึ้น (ดูหัวข้อด้านล่าง)

## เหมาะกับใคร

ถ้าใช้ SillyTavern **เครื่องเดียว** แล้วเข้าจากมือถือ/คอมผ่านเน็ตหรือ tunnel ได้แล้ว — **ไม่ต้องใช้ตัวนี้** ง่ายกว่ามาก

ใช้ TavernSync เมื่อมี SillyTavern แยกจริง ๆ เช่น คอมบ้าน ↔ โน้ตบุ๊ก อยากพกแชทตอนออฟไลน์ หรือไม่อยากฝากเรื่องราวไว้บนเซิร์ฟเวอร์คนอื่นทั้งก้อน

## ติดตั้ง

ไม่ต้องลง Node หรือ build อะไร — ติดตั้ง extension อย่างเดียว

1. ใน SillyTavern ไป **Extensions** → **Install extension**
2. วางลิงก์: `https://github.com/SICout9010/st-tavernsync`  
   (ถ้ามี **Install for all users** แนะนำเลือกอันนั้น)
3. เปิดใช้ **TavernSync**
4. เปิดแผง Extensions ทางขวา แล้วหาหัวข้อ **TavernSync**

## เริ่มใช้ครั้งแรก

### 1) มีที่เก็บกลาง (sync server)

ตอนนี้ต้องใช้เซิร์ฟเวอร์ของตัวเอง (เช่น Cloudflare Worker ในโฟลเดอร์ [`worker/`](worker/)) — ยังไม่มี Managed ให้กดใช้เลย  
รายละเอียด deploy อยู่ที่ [README_DEV.md](README_DEV.md) และ [`worker/README.md`](worker/README.md)

### 2) กรอกในแผง TavernSync (ทุกเครื่อง)

| ช่อง | ใส่อะไร |
|------|---------|
| **Server URL** | URL ของ sync server เช่น `https://xxxx.workers.dev` — **อย่าใส่ `/` ท้าย** |
| **Device name** | ชื่อเครื่องนี้ เช่น `คอมบ้าน` / `มือถือ` (คนละเครื่องคนละชื่อ) |
| **Sync token** | รหัสลับร่วมกันของบัญชีซิงก์นี้ — **อย่าใช้รหัสล็อกอิน SillyTavern** |

กด **Test** ให้แน่ใจว่าต่อได้

### 3) ปลดล็อกการเข้ารหัส (ครั้งแรกต่อเครื่อง)

E2EE **เปิดเป็นค่าเริ่มต้น**

1. คิด **passphrase** เดียวกันทุกเครื่อง แล้วจดเก็บไว้ที่ปลอดภัย  
2. ใส่ passphrase → ติ๊ก **I've saved my passphrase** → กด **Unlock**  
3. จากนั้นเครื่องนี้จะจำคีย์ไว้ (ไม่ต้อง Unlock ทุกครั้งที่รีเฟรช)  
4. ถ้าอยากให้ถามทุกครั้งที่รีเฟรช ค่อยเปิด “Ask for passphrase after every refresh”

**ทำ passphrase หาย = ข้อมูลบนเซิร์ฟเวอร์กู้ยากมาก** — พึ่งแบ็กอัปในเครื่องด้วยเสมอ

### 4) ซิงก์รอบแรก (แนะนำ)

สมมติ **คอมมีข้อมูลครบ** แล้วอยากย้ายไปอีกเครื่อง:

1. บนเครื่องต้นทาง → **↑ Push**  
2. บนเครื่องปลายทาง → กรอก URL / token / passphrase ชุดเดียวกัน → Unlock → **↓ Pull**  
3. ถ้าขึ้นให้รีโหลดหน้าหลังดึง settings/personas — กดรีโหลดได้เลย

คำสั่งในแชท: `/sync-push` · `/sync-pull` · `/sync-status`

## ปุ่มสำคัญ

| ปุ่ม | ความหมาย |
|------|----------|
| **Push** | ส่งของในเครื่องนี้ขึ้นเซิร์ฟเวอร์ |
| **Pull** | ดึงจากเซิร์ฟเวอร์ลงเครื่องนี้ |
| **Check status** | เทียบกับเซิร์ฟเวอร์ (จะสแกน) |
| **Rescan this device** | สแกนข้อมูลในเครื่องใหม่แบบกดเอง |
| **Lock this device** | ลืมคีย์ที่จำไว้ ต้อง Unlock ใหม่ |
| **Wipe server sync data** | ล้างดัชนีบนเซิร์ฟเวอร์ (ไม่ลบไฟล์ใน SillyTavern เครื่องคุณ) |

เปิดแผง TavernSync จะสแกนเงียบ ๆ ให้อยู่แล้ว (ไม่มี toast รบกวน)

## Conflict คืออะไร / กดอะไรดี

Conflict = ของชิ้นเดียวกันถูกแก้ทั้งฝั่งเครื่องนี้และเซิร์ฟเวอร์ (หรือ baseline ซิงก์หลุด)

ตอน **Push** ถ้ามี conflict หลายชิ้น:

1. **OK = Skip conflicts (ปลอดภัย)** — ส่งเฉพาะของที่ไม่ชน ไม่วนทับเซิร์ฟเวอร์ทั้งก้อน  
2. Cancel แล้วค่อยเลือก **Force overwrite** ได้ แต่ทำได้เฉพาะเมื่อมั่นใจว่า **เครื่องนี้มีของครบและถูก**  
3. หรือเลือกทีละชิ้น: เก็บเครื่องนี้ / เก็บเซิร์ฟเวอร์ / เก็บทั้งคู่ / ข้าม

**อย่า Force overwrite จากเครื่องที่ Pull ไม่ครบ**  
ตัวอย่างอันตราย: PC Push ของดี → มือถือ Pull พลาดบางไฟล์ → มือถือ Push ทับเซิร์ฟเวอร์ → PC Pull แล้วข้อมูลหาย

ถ้า Pull มีของถูก skip / decrypt ไม่ได้ ระบบจะเตือนว่า baseline ยังไม่ครบ — **อย่าใช้เครื่องนั้นเป็นต้นทาง Push** จนกว่า Pull จะสะอาด หรือ Wipe เซิร์ฟเวอร์แล้ว Push จากเครื่องที่มีของจริง

**Keep both** (โดยเฉพาะแชท) จะเก็บของเครื่องนี้ไว้ แล้วเซฟฝั่งเซิร์ฟเวอร์เป็นชื่อสำรองแบบ `(conflict วันที่ ชื่อเครื่อง)`

## ข้อแลกของ E2EE (อ่านสักนิด)

ชุมชนมักอยากได้ความเป็นส่วนตัว → TavernSync เปิด E2EE เป็นค่าเริ่มต้น แต่มีข้อแลกจริง ๆ:

| ได้ | แลก |
|-----|-----|
| คนดูเซิร์ฟเวอร์อ่านแชทยากขึ้น | ต้องมี passphrase + Unlock อย่างน้อยครั้งแรกต่อเครื่อง |
| ข้อมูลบน R2 เป็น ciphertext | passphrase หาย = กู้ของบนเซิร์ฟเวอร์ยากมาก |
| จำคีย์บนเครื่องได้ (ไม่ต้อง Unlock ทุกรีเฟรช) | คีย์ที่จำไว้อยู่ในเบราว์เซอร์ — กันเซิร์ฟเวอร์ได้ **ไม่กัน** extension อื่นบนโปรไฟล์เดียวกัน |

ถ้าปิด E2EE ได้ (Advanced / ยกเลิกติ๊ก encryption) ใช้งานง่ายขึ้น แต่คนที่เข้าถึงเซิร์ฟเวอร์อาจอ่านเนื้อหาได้

## สิ่งที่ซิงก์ได้

Settings · Characters · Chats · Lorebooks · Presets · Personas · Groups · (Themes / Quick replies ยังไม่ครบฝั่ง apply)

**คีย์ API ของโมเดลจะไม่ถูกซิงก์** — ตั้งใจตัดออก

“Delete on other devices too” **ปิดเป็นค่าเริ่มต้น** — เปิดเมื่อตั้งใจลบจริง ๆ เท่านั้น

## ถ้าพัง

1. ก่อน Pull ใหญ่ ๆ สำรองโฟลเดอร์ข้อมูล SillyTavern ไว้ก่อน  
2. Passphrase หาย → พึ่งแบ็กอัปในเครื่อง  
3. **Reset sync on this device** = ล้างสถานะซิงก์ในเบราว์เซอร์ ไม่ลบตัวละคร/แชทใน ST  
4. ดัชนีเซิร์ฟเวอร์พัง / blob หาย → **Wipe server sync data** แล้ว Push จากเครื่องที่มีของจริง  
5. ดูคอนโซลเบราว์เซอร์ คำว่า `[TavernSync]`
